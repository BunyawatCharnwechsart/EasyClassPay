# EasyClassPay

## ระบบจัดการค่าใช้จ่ายและการชำระเงินร่วมกัน

**Group Project — Software Process × Fundamental of Database Systems**

EasyClassPay เป็นเว็บไซต์สำหรับจัดการค่าใช้จ่ายและการชำระเงินร่วมกันภายในกลุ่ม
ช่วยให้ผู้ใช้งานสามารถบันทึกรายการค่าใช้จ่าย แบ่งค่าใช้จ่ายระหว่างสมาชิก
และติดตามสถานะการชำระเงินของแต่ละคนได้อย่างสะดวกและเป็นระบบ
